# 🗳️ Online Voting System

## 📌 Project Description
This is a web-based Online Voting System developed using PHP and MySQL. 
It allows users to register, login, and cast their vote securely. 
The system ensures that each user can vote only once and displays real-time voting results.

## 🚀 Features
- User Registration & Login
- Secure Voting System
- One User One Vote Validation
- Admin Dashboard
- Real-time Result Display
- Logout System

## 🛠️ Technologies Used
- HTML
- CSS
- JavaScript
- PHP
- MySQL

## 📂 Project Structure
- index.php (Home Page)
- login.php (User Login)
- vote.php (Voting Page)
- result.php (Result Page)
- database.sql (Database File)

## ▶️ How to Run
1. Install XAMPP or WAMP
2. Copy project folder to htdocs
3. Import database.sql in phpMyAdmin
4. Start Apache and MySQL
5. Open http://localhost/online-voting-system
